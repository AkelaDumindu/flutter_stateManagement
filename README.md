# Flutter Cart and Favorites App  

This application is a small project developed to practice and master Flutter state management techniques using the Provider package. The app allows users to add items to a cart and manage their favorite items while ensuring real-time updates and a seamless user experience.  

## Features  

- **Cart Management**:  
  Users can add items to their cart, and the app dynamically updates the cart in real time.  
- **Favorites Management**:  
  Users can mark items as favorites and view them in a dedicated section for personalized interaction.  
- **State Management**:  
  The project focuses on implementing state management techniques using Flutter's Provider package to maintain consistency and responsiveness.  

## Technology Stack  

- **Flutter**: Framework used for building the UI.  
- **Dart**: Programming language for application logic.  
- **Provider**: State management package ensuring efficient updates and synchronization.
